# TiendaOnline

Aplicación web de una tienda online desarrollada en equipo con **Java** y **Spring Boot**.

## Descripción

TiendaOnline permite gestionar una tienda por internet: ver los productos del catálogo, registrarse, añadir productos al carrito y realizar pedidos. El proyecto está hecho como trabajo grupal para practicar el desarrollo de aplicaciones con Spring Boot y el trabajo en equipo con Git y GitHub.

## Funcionalidades

- Catálogo de productos (listar, buscar y ver detalle)
- Registro e inicio de sesión de usuarios
- Carrito de la compra
- Gestión de pedidos
- Administración de productos (crear, editar y eliminar)

## Tecnologías

- Java 17
- Spring Boot
- Maven
- Base de datos: MySQL / PostgreSQL (elegid una)
- IntelliJ IDEA
- Git y GitHub

## Cómo ejecutar el proyecto

1. Clona el repositorio:
```bash
   git clone https://github.com/TU_USUARIO/TiendaOnline.git
```
2. Abre el proyecto en IntelliJ IDEA.
3. Configura la base de datos en `src/main/resources/application.properties`.
4. Ejecuta la clase principal con `@SpringBootApplication`.
5. Abre en el navegador: `http://localhost:8080`
